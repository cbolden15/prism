# Changelog

This file records public Prism releases.

## [0.1.0] - 2026-09-03 (developer preview)

- Published `@useprism/sdk`, `@useprism/runtime`,
  `@useprism/provider-ollama`, and `@useprism/cli`.
- Added registry-first deterministic onboarding and retained the offline
  four-tarball acceptance path.
- Included the bounded deterministic agent loop, optional direct Ollama path,
  run inspection, and project-pinned tool-plugin workflow.
- Kept `packages/provider-codex` source-visible and unpublished.
- Documented local data handling, ambient subprocess authority, incomplete
  assurance evidence, and developer-preview compatibility limits.
