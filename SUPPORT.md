# Support

Prism 0.1.0 is a developer preview. Use GitHub Issues for reproducible bugs,
documentation gaps, and narrowly scoped feature requests. Include the Prism,
Node.js, npm, and operating-system versions plus the smallest safe reproduction.

Do not include credentials, private repository content, provider prompts or
responses, local run records, approval state, host details, or personal data.
Report suspected vulnerabilities through the private process in `SECURITY.md`.

Only the current 0.1.x line is maintained. The project does not promise a
response time or compatibility before a stable release.
