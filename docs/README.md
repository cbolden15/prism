## Documentation layers

The developer-preview guides describe public 0.1.0 behavior. The architecture
page shows how the current packages and execution paths fit together. The
examples are small, runnable starting points. `docs/plans/` contains design
history and implementation records; use it when investigating why a decision
was made, not as the first product guide.
